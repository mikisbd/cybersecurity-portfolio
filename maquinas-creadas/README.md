## 🛠️ Detalle de cada Máquina

### 1. 💓 Pulse
* **Plataforma**: [HackMyVM](https://hackmyvm.eu/machines/machine.php?vm=Pulse)
* **Sistema**: Linux
* **Ficha oficial**: [Ver máquina en HackMyVM](https://hackmyvm.eu/machines/machine.php?vm=Pulse)
* **Descarga**: [Mega.nz (OVA)](https://mega.nz/file/3oU2zZLb#JJU5CyrYP8cX0FFWuYtB552K0ZKbJtn0BwggoHkO_1Y)
* **Concepto**: Máquina diseñada para evaluar el reconocimiento metódico de puertos y servicios, descubrimiento de aplicaciones web y vectores de escalada de privilegios en Linux.

### 2. ⚙️ Automatismos Rodriguez
* **Plataforma**: [TheHackersLabs](https://labs.thehackerslabs.com/machine/283)
* **Sistema**: Linux

### 3. 🧪 Flasky
* **Plataforma**: [DockerLabs](https://dockerlabs.es/)
* **Sistema**: Linux (Contenedor Docker)
* **Descarga**: [Descargar flasky.zip](https://gestion-maquinas.dockerlabs.es/dl/flasky.zip)
* **Concepto**: Entorno centrado en el framework Flask / Python. Explotación de vulnerabilidades web en microframeworks y escape o elevación de privilegios dentro del contenedor.

---

### 4. 🚗 Autoescuela

### 5. 🔮 Profetas

### 6. ⏳ CuentaAtrás
